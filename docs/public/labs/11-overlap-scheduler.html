概念化代码锚点（不等同于逐行源码）serial = steps × (cpu_prepare + gpu_forward) overlap = cpu_prepare + gpu_forward + (steps - 1) × max(cpu_prepare, gpu_forward)
你的解释锚点：GPU 正在执行第 n 步时，CPU 尽量准备第 n+1 步。只有 CPU 工作不比 GPU 慢时，CPU 才可能主要被隐藏。
