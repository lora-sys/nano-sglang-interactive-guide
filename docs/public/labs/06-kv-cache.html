概念化代码锚点（不等同于逐行源码）blocks = ceil(sequence_length / block_size) capacity = blocks × block_size unused_slots = capacity - sequence_length
先承诺预测：不要把 logical sequence length 当作已经连续占满一整块物理数组。allocator 先决定页数，再由最后一页承载可能的内部碎片。
block、slot 与利用率是概念 allocator 状态机，不代表特定 backend 的完整 page table、free-list 或真实显存占用。
